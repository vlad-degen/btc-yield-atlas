# Maple «BTC Yield» (совместно с Core Foundation): углублённый разбор

*Скрипты: [`tools/top5/maple/`](../../tools/top5/maple/), данные: [`data/top5/maple/`](../../data/top5/maple/). Упоминания `scripts/` и `raw/` ниже относятся к рабочей папке; сырые выгрузки `raw/` не публикуются.*
*Английский оригинал: [en/06-maple.md](en/06-maple.md).*

Дата исследования: 2026-09-21. Охват: институциональный продукт Maple BTC Yield, который использовал двойной стейкинг (dual staking) в Core с займом в USDC, покупкой CORE и пут-опционами на CORE; связанный с ним lstBTC; syrupBTC; а также спор Core Foundation против Maple.

**Как читать этот отчёт**
- **РАСКРЫТО**: заявлено Maple, Core или судом.
- **ОНЧЕЙН**: восстановлено мной по данным блокчейнов Core или Bitcoin. Метод атрибуции и уровень уверенности — в §0.3.
- **ОЦЕНКА**: моя оценка. Исходные данные каждый раз указаны.
- **НЕ НАЙДЕНО**: данные найти не удалось. Указываю, что нужно, чтобы их получить.

Сопутствующие файлы в этой папке:
- `size_history.csv`
- `yield_history.csv`
- `events.csv`
- `scripts/`: все цифры здесь воспроизводимы.
- `raw/`: дампы API, судебные PDF, переведённые в текст, и ончейн-выгрузки.

## 0. Главное (открытый вопрос: текущий размер и статус)

**Как действующий продукт он больше не существует. Текущий размер — 0 BTC.**

1. **Запись в API Maple всё ещё есть, но скрыта.** В публичном GraphQL API Maple есть запись пула `poolMeta(id: 67e542004191822941f9e703)` с `poolName: "BTC Yield"`, `state: "Hidden"` и `withdrawalDays: 60`. Её ключевые показатели застыли на «Дата следующего погашения: 27 июня 2025». Метка времени ObjectId показывает, что запись создана 2025-03-27. Публичная страница продукта отдаёт 404. Protos сообщил, что раздел сайта о BTC-доходности удалили около 2025-11-20. Снимок: `raw/maple_btc_yield_poolmeta.json`.
2. **В Core больше ничего не застейкано.**
   - Все CLTV-стейки адресов, отнесённых к Maple, истекли к **2025-11-19**, и новых с тех пор не было.
   - Нога ~50.7M CORE была выведена из стейкинга в период с **2026-03-29 по 2026-05-12**.
   - Собственный системный токен lstBTC в Core (`0x…010001`, «Core BTC LST») имеет **totalSupply = 0**. API стейкинга возвращает `btc_lst_apr = 0`.
   - Все страницы lstBTC (блог Core, документация, lstbtc.coredao.org) отдают 404.
3. **Кредиторы получили обратно 85% в BTC.** В сети Bitcoin оставшиеся **1,333.78 BTC** 2025-11-19 были сведены на один хаб-кошелёк (`bc1pm9v0y2…c0pc4`). **1,133.69 BTC (85.0%)** выплачены на **66 адресов** в период с 2025-11-19 по 2025-12-22, с небольшим хвостом до 2026-08-10. **200.09 BTC (15.0%)** были отложены. Это совпадает с заявлением Maple от 2025-11-21: «вернуть 85% основной суммы в BTC … оставшиеся 15% удерживаются … будут освобождены после успешного завершения судебных разбирательств».
4. **Куда ушли удержанные 15%, публично неизвестно.** **2026-06-05**, через 14 дней после мирового соглашения от 2026-05-22, удержанные 200.0 BTC ушли **одним переводом** через существовавший ранее промежуточный адрес на кошелёк `bc1q5zly2…` (≈2,263 BTC совокупного оборота за всё время). Владелец не раскрыт. По блокчейну нельзя понять, было ли это освобождение средств в пользу кредиторов, погашение USDC-ноги или платёж по мировому соглашению. Условия соглашения конфиденциальны.
5. **syrupBTC не запущен.** В мировом соглашении сказано: «Maple продолжит запуск … syrupBTC в обычном порядке». По состоянию на 2026-09-21 я **не нашёл syrupBTC**:
   - нет токена в Ethereum, Base или Arbitrum (поиск в Blockscout);
   - нет пула в API Maple (`poolsMeta` и `syrupTokens` выдают только токен Syrup и syrupUSDC/USDT/USDG);
   - нет упоминаний в мемо 2026 года, в обновлении за Q2-2026 или в посте «allocation strategies» от 2026-09-02, где вместо этого перечислены прямое кредитование, ABS и базисная сделка на CME.

   **Статус: не запущен (НЕ НАЙДЕНО).**

### 0.1 Чем продукт был на самом деле (новые выводы по сравнению с §4.12 репозитория)

- **Контрагентом по хеджу CORE была сама Core Foundation.**
  - Хедж — пут-опционы на CORE с физической поставкой по **Генеральному торговому соглашению (Master Trading Agreement) от 27 февраля 2025**. Core Foundation должна была «выкупить токены CORE по этому пут-опциону» по страйку.
  - Core Foundation обеспечила его **денежным залогом US$5M**.
  - По словам Core: «Мы месяцами исполняли каждую экспирацию путов, выплатив миллионы долларов».
  - Core перестала платить по путам, срок которых наступил 30 сентября 2025.
- **Это был риск неблагоприятной корреляции (wrong-way risk).** Продавцом хеджа был эмитент токена, и он же был коммерческим партнёром, с которым возник спор.
- **Одни лишь награды за стейкинг не могли дать 5%+.**
  - ОНЧЕЙН: адреса Maple забрали наград на **4.66M CORE** за **848 BTC-лет**. Это **валовая доходность двойного стейкинга ≈1.9% годовых в выражении в BTC** (по ценам на даты клейма) и **≈2.7%** даже по средневзвешенной по BTC цене CORE ($0.527).
  - Это до вычета стоимости займа в USDC (ОЦЕНКА ≈1.2–1.5% годовых от стоимости BTC).
  - Поэтому для заявленных 5.1–5.6% нетто требовалось примерно **3.5–4.5 п.п. годовых из источников вне стейкинга**. Наиболее вероятный источник — выплаты по путам / субсидия от Core Foundation (ОЦЕНКА).
- **Экономика для кредиторов.** Согласно судебным материалам, кредиторы «предоставили свои биткоины в заём» сегрегированному портфелю по генеральному договору займа. Займы автоматически пролонгировались, если не было требования о погашении.
- **Плечо.** Maple занимала USDC под этот BTC, чтобы купить CORE-ногу:
  - 50.5M CORE на пике, то есть 34,000 CORE/BTC × 1,485 BTC.
  - «Более 40 млн CORE … куплено … более чем за US$20 млн» (судебные материалы).
  - Расчётный LTV ≈ **13–16% (ОЦЕНКА)**.
- **CORE упал на ≈94% с момента набора CORE-ноги до её закрытия.** При покупке CORE-нога стоила ≈$28M (ОЦЕНКА), а ≈$1.4–3.3M — в марте–мае 2026. Этот убыток — около 15% основной суммы в BTC, то есть столько же, сколько **удержанные 15%** (ОЦЕНКА; очень показательное совпадение).

### 0.3 Метод атрибуции и уровень уверенности (ончейн)

- **Исходный адрес.** У адреса для наград Core `0x74bb2c9f…` сроки CLTV: **584.047 BTC на 2025-10-15** и **756.983 BTC на 2025-11-19**. Решение суда Каймановых островов от 10 октября 2025 упоминает «примерно 584 биткоина … со сроком 15 октября 2025» и обязательства по погашению «15 октября и 19 ноября 2025».
- **Связанные адреса.** Ещё четыре адреса для наград стейкают BTC под теми же четырьмя скриптами владельца в Bitcoin (2 P2PKH и 2 P2WSH-мультисига 2 из 3):
  - `0xadfaaa5f…`, первый стейк 2025-03-26;
  - `0xfd818e35…`, первый стейк 2025-02-06;
  - `0x87f34109…`;
  - `0x2ed725c8…`.

  Кошелёк, финансировавший CORE, `0x34a8b81a…` тоже встречается под одним из этих скриптов. См. `scripts/cluster_link.py`.
- **Сторона Bitcoin.** Транзакции стейкинга BTC прослеживаются в сети Bitcoin (mempool.space). Их финальный свип приходит на единый хаб, выплаты с которого составляют ровно 85%/15% от собранной суммы.
- **Уверенность.** Высокая — в том, что этот кластер и есть программа BTC Yield. Средняя — в том, что это *вся* программа: ранние стейки с других кошельков могли быть упущены, при этом раскрытые 1,600+ BTC против ончейн-значений 1,570–1,758 BTC около 1–14 мая хорошо согласуются.

## B. Механика по шагам (с параметрами)

1. **Депозит / займ BTC.**
   - Кредитор подписывает генеральный договор займа и предоставляет BTC в заём Maple International Operations SPC (BTC Staking SP 1).
   - BTC хранится у кастодиана (BitGo или Copper) на кошельках, контролируемых в интересах SP.
   - Maple продвигала это как «никогда не отдаётся в заём, не оборачивается и не перезакладывается». Юридически же кредитор выдаёт SP займ в BTC, а SP затем закладывает этот BTC под займ в USDC (см. шаг 3).
2. **CLTV-стейкинг биткоина в Core.**
   - Каждый стейк — это транзакция Bitcoin на P2WSH-скрипт `<locktime> OP_CLTV OP_DROP <custodian owner script>` с OP_RETURN, в котором указаны валидатор Core и адрес для наград в CORE.
   - Никаких мостов или обёрток. BTC нельзя переместить до наступления locktime.
   - ОНЧЕЙН: 221 транзакция стейкинга, 12,296 BTC брутто (включая повторные стейки), по **33 валидаторам**.
   - Блокировки были короткими и переходящими. Взвешенно по BTC: 65% стейков заблокированы на ≤15 дней, 24% — на 36–65 дней, 4% — на 66–95 дней.
   - Сроки были разнесены во времени, например: 1,000 BTC на 2025-05-15, 904 BTC на 08-20, 584 BTC на 10-15 и 757 BTC на 11-19.
3. **Займ в USDC под залог BTC.**
   - «Maple использует внесённый BTC как залог для займа USDC через свою внутреннюю инфраструктуру» (OAK).
   - В судебных материалах упоминаются обязательства перед «инвесторами, предоставившими свои биткоины в заём», **или** «инвесторами другого связанного сегрегированного портфеля». Это явно указывает на то, что USDC поступил из другого сегрегированного портфеля или пула под управлением Maple (вывод).
   - **Кредитор: НЕ НАЙДЕНО. Ставка: НЕ НАЙДЕНО.** Для получения этих данных нужна отчётность SP или подтверждения по займам. Для ориентира: институциональные займы Maple стоят около 6–12% (мемо 2026 года), а целевая ставка обеспеченного пула — 9%.
   - **LTV ≈13–16% (ОЦЕНКА)**, исходя из того, что потребность в USDC на каждый BTC = коэффициент уровня × цена CORE. Например, 34,000 CORE/BTC × $0.50 = $17k на BTC при цене BTC $115k. Это согласуется с формулировкой суда «584 биткоина, что эквивалентно примерно US$9 млн» (= $15.4k на BTC), которую я понимаю как сумму в USD, необходимую для высвобождения этих BTC.
4. **Покупка CORE.**
   - ОНЧЕЙН: CORE шли с высокообъёмного кошелька (`0xe41bae1d…`, nonce > 109k, баланс 44M CORE, вероятно, биржа; вывод) → `0x9509e801…` → кошелёк финансирования Maple `0x34a8b81a…` → адреса для наград.
   - Застейканная CORE-нога выросла с 0.4M (6 февраля) до 39.6M (24 апреля), 45.5M (8 мая) и **50.5M (10 июля 2025)**.
   - Суд: у Maple было «>40 млн токенов CORE, которые они законно купили сами более чем за US$20 млн». Core также предоставила CORE «в качестве залога», и на 26 сентября у Maple находилось «около US$27 млн» активов Core.
   - ОЦЕНКА себестоимости ноги: ≈$25–28M (в среднем ≈$0.53–0.56).
5. **Защитные путы (хедж).**
   - Путы с физической поставкой по MTA от 27 февраля 2025. **Контрагент: Core Foundation** («одна из этих третьих сторон», по словам Core; Maple: «опционы, обеспеченные денежным залогом, предоставленным CORE Foundation по нашему соглашению»).
   - Залог — US$5M денежными средствами.
   - Срок: экспирации следовали графику погашений BTC; путы «подлежали исполнению 30 сентября 2025 или подлежат исполнению 15 октября 2025».
   - Конструкция: «структурированная стратегия защитных путов при входе … для покрытия как основной суммы, так и ожидаемых наград»; «размер позиции ограничен ёмкостью хеджа» (OAK).
   - **Премия / стоимость: НЕ НАЙДЕНО.** Core называет свои расходы «субсидиями продукта», что говорит о том, что путы достались Maple бесплатно или дёшево (вывод). Для определения премии нужен MTA.
6. **Уровень двойного стейкинга.** Maple держала уровень Satoshi (высший). События клейма (ОНЧЕЙН) показывают `dualStakingRate` 40000 → 60000/45000/32500 → 50000, что соответствует мультипликаторам Satoshi ниже. Пороги Core по событиям управления BitcoinAgent:

| Действует с | Base | Boost | Super | Satoshi (CORE на BTC → мультипликатор) |
|---|---|---|---|---|
| 2024-11-20 | 0 → 20% | 1,000 → 35% | 3,000 → 85% | **8,000 → 1000%** (затем 800/600/500/400%) |
| 2025-02-27 | 0 → 20% | 2,000 | 6,000 | **16,000 → 400%** (625% с 03-05, 230% с 03-25) |
| 2025-04-03 | 0 → 20% | 3,000 | 9,000 | **24,000 → 230%** |
| 2025-04-08 | 0 → 10% | 3,000 → 20% | 9,000 → 30% | **24,000 → 400%** (250% с 06-03) |

7. **Награды.**
   - Награды поступают в CORE по BTC-ноге и CORE-ноге (всего 4.66M CORE).
   - Их периодически отправляли на `0xc027ac0b…`, а оттуда — на кошелёк, похожий на биржевой (перемещено 7.4M CORE). Это согласуется с формулировкой «награды конвертируются обратно в BTC».
   - Доходность в BTC выплачивалась с хаба. Один идентифицируемый адрес кредитора получил 0.3077 BTC (август), 0.0662 BTC (сентябрь) и 0.045 BTC (октябрь 2025) при расчётной основной сумме ~25 BTC. **Ежемесячные выплаты по кредиторам: НЕ НАЙДЕНО**, кроме этого одного адреса.
8. **Погашение.**
   - Уведомление подаётся за 2 недели до очередного погашения (раз в два месяца).
   - При погашении SP должен (a) дождаться истечения CLTV и (b) погасить USDC, привязанный к этому BTC, продав CORE или исполнив путы.
   - После этого BTC возвращается с кошелька кастодиана кредитору.
   - CORE можно вывести из стейкинга в любой момент, без периода анбондинга (документация Core). Реальные ограничения — продажа CORE / расчёт по путам и дата CLTV.

## C. Цепочка контрагентов и кому принадлежит ликвидность на каждом шаге

```
BTC кредитора ──займ (MLA, автопролонгация)──► Maple Int'l Ops SPC – BTC Staking SP 1  (владеет требованием на BTC; кредитор = необеспеченный? кредитор SP)
    │                                          │
    │  хранение: кошельки BitGo / Copper (4 скрипта владельца + taproot-хаб)  ◄── ключи у кастодиана; SP — бенефициарный владелец
    │                                          │
    ├─► выходы Bitcoin CLTV P2WSH (заблокированы до погашения; до locktime их не может переместить ни третья сторона, ни кастодиан)
    │                                          │
    ├─► заложены под займ в USDC ◄── кредитор в USDC (вероятно, «другой связанный сегрегированный портфель» Maple – вывод)
    │                                          │
    ├─► USDC → CORE, купленные на рынке/OTC (≈50.5M CORE, принадлежат SP) + CORE, внесённые Core Foundation в залог
    │                                          │
    ├─► пут-опционы на CORE (с физической поставкой) ◄── продавец: Core Foundation (+US$5M денежного залога)   ← риск неблагоприятной корреляции
    │                                          │
    └─► валидаторы Core (задействовано 33; например, пулы DAO, Solv, stc Bahrain, BTCS…) – без хранения, только атрибуция наград
```

- **Кому принадлежит ликвидность.**
  - BTC: кастодиан (ключи) и SP (юридический владелец). У кредитора — договорное требование к SP.
  - CORE: адреса SP для наград.
  - Ценность хеджа зависит от готовности и способности Core Foundation платить (она перестала).
  - У кредитора в USDC есть обеспечительное право на BTC.
- **Что изменилось в кризис.** Когда Core перестала исполнять путы и добилась судебного запрета, замораживающего любые операции с CORE, SP не мог превратить CORE в USDC. Следовательно, он не мог высвободить BTC, обеспечивавший USDC. Отсюда «обесценение» (impairment), разделение 85/15 и удержание.

## F. Управление рисками

- **Маржа по займу в USDC.** При LTV ~15% ценовой риск BTC был невелик: чтобы пробить типичные пороги, BTC должен был бы упасть на ~80–85%. **Условия маржи: НЕ НАЙДЕНО.** Реальный риск был в активе, купленном на USDC (CORE), а не в BTC.
- **Ценовой риск CORE.**
  - Хеджировался только путами партнёра: единственный контрагент, он же эмитент, с денежным залогом $5M против позиции в CORE на ~$25M+ (покрытие ≈20%, ОЦЕНКА).
  - Хедж отказал именно тогда, когда был нужен: CORE падал вместе с делами самой Core (DeFi TVL сети Core снизился с $877M в феврале 2025 до $47M в декабре 2025 и $5M в 2026, по данным DefiLlama).
  - Рискованной была и ликвидность. 50.5M CORE — это ≈3.4% обращающегося предложения, а суду сообщили, что дневной объём торгов составлял около 66M CORE при цене $0.40.
- **Ликвидность и погашение.** BTC заблокирован до каждой даты CLTV. Ликвидность кредитора зависит ещё и от погашения USDC, а для этого нужна ликвидность CORE или расчёт по путам. Цикл 60 дней / раз в два месяца с уведомлением за 2 недели не даёт ликвидности по требованию. Займы автоматически пролонгируются, если кредитор не потребует погашения.
- **Кастодиальный риск.** Квалифицированные кастодианы (BitGo, Copper). Благодаря CLTV-скриптам даже кастодиан не может переместить BTC до погашения. Инцидентов с хранением я не увидел. Все 221 застейканных выхода были потрачены только после наступления срока — на повторные стейки, хаб-кошелёк или другие кошельки, похожие на собственные кошельки программы (не каждый адрес назначения я проверил).
- **Юридический / партнёрский риск (реализовался).**
  - Спор об эксклюзивности позволил партнёру (a) прекратить выплаты по хеджу и (b) добиться ex parte заморозки любых действий с CORE, включая анстейкинг и хеджирование.
  - Изоляция через сегрегированный портфель защитила другие продукты Maple (syrupUSDC и syrupUSDT не пострадали), но *не* кредиторов этого продукта.
- **Риск параметров протокола.** Управление Core может в любой момент менять пороги уровней и мультипликаторы. Это происходило 16 раз, включая 8,000 → 68,000 CORE/BTC.

На хаб-кошелёк Maple видны внешние поступления 1,615 BTC (июнь 2025), 464 (июль), 71 (август), 344 (сентябрь) и 23 (октябрь) — скорее всего, это консолидация стейков с наступившим сроком, а не новые депозиты (вывод).
- К цели Maple на конец года в $1.5B (bitcoin.com / OAK) даже не приблизились.

## I. Драйверы роста и что его остановило

- **Драйверы.**
  1. Совместный маркетинг и «субсидии» Core: запуск на Consensus HK, блог Core и путы, которые обеспечивали BTC-доходность 5%+.
  2. Нативное хранение без обёрток через BitGo и Copper, что подходило институционалам.
  3. Это была одна из немногих доходностей ~5% на «нативный BTC» в H1 2025.
  4. Институциональная дистрибуция Maple. Core утверждает, что BTC-продукт «помог дать старт взрывному росту Maple» (на момент партнёрства у Maple было менее $500M AUM; TVL Maple по DefiLlama вырос с $298M в марте 2025 до $3.1B в ноябре 2025).
- **Что его остановило.** Рост остановился на ~1.5–1.76k BTC к июню 2025, ещё до спора. Причины:
  1. **Ёмкость хеджа**: «размер позиции ограничен ёмкостью хеджа», а продавцом хеджа была Core.
  2. Коэффициент уровня вырос с 24k до 34k CORE/BTC (апрель–июль 2025), требуя больше CORE на каждый BTC.
  3. Устойчивое снижение CORE от максимума мая 2025.
  4. Maple переключилась на syrupBTC (по утверждению Core — с середины 2025). lstBTC так и не запустили.
- **Затем спор поставил на продукте точку.** Сентябрь–ноябрь 2025: неоплаченные путы, судебный запрет, сворачивание, 85/15.
- **Интеграции с кастодианами.** BTC продукта хранили BitGo и Copper. Hex Trust фигурировал только в анонсе lstBTC. **Минт lstBTC или держатели: не найдены** (предложение системного lstBTC в Core = 0; ERC-20 не найден; страницы удалены).
- **Более широкий рост Maple** (syrupUSDC/USDT; $4.6B AUM на конец H1 2026, $4.8B в августе 2026) после Q3 2025 не был связан с BTC Yield. В материалах Maple за 2026 год продукт не упоминается.

## J. Экономика

**Доход Maple от комиссий (ОЦЕНКА).**

| Статья | Оценка |
|---|---|
| Комиссия за управление | 0.40% × ~$150M в среднем × ~0.75 года ≈ **$0.45M** |
| Комиссия за результат | 20% × (≈5.5% брутто − 5%) × ~$150M × ~0.5 года ≈ **$0.1M** |
| **Комиссии за весь срок** | **≈$0.5–0.6M** |
| В годовом выражении на пике | ≈$0.8M |

Для сравнения: ARR Maple составлял $15M в Q2 2025. Судебные издержки по спору (обе стороны «полностью финансировали» процесс), вероятно, превысили эти комиссии (вывод).

**Экономика стимулов в CORE (сторона Core Foundation, ОЦЕНКА).**
- Core выплатила «миллионы» по расчётам по путам (март–август 2025), внесла $5M денежного залога и предоставила CORE в качестве залога.
- Взамен Core получила:
  - ~1.5–1.76k BTC в стейкинге (≈24–30% всех BTC, застейканных в Core);
  - спрос на ~50M CORE (≈3.4% обращающегося предложения);
  - децентрализацию валидаторов (Maple распределила стейки по 33 валидаторам);
  - громкий заголовок «институциональная BTC-доходность».
- Расчётная стоимость субсидии ≈ $0.6M в месяц ≈ 4–5 п.п. годовых на ~$160M в BTC (ОЦЕНКА).
- **Сама CORE-нога (ОЦЕНКА).** Куплена за ≈$25–28M; стоила ≈$8.3M на 2025-11-19 и ≈$1.4–3.3M при выводе из стейкинга в марте–мае 2026.
- **Убыток ≈$22–26M.** Его в той или иной пропорции поглотили SP/кредиторы (15% ≈ $17M на тот момент), кредитор в USDC, Maple и Core (через мировое соглашение). **Распределение: НЕ НАЙДЕНО (конфиденциально).**
- **Время выхода из CORE (ончейн; не утверждение о причинно-следственной связи).**
  - 25.9M CORE были выведены из стейкинга и перемещены в период с 2026-03-29 по 04-02 через промежуточные адреса на пересылочные адреса с низким nonce.
  - CORE упал на ~49% в день 2026-03-29. Core DAO объяснила падение «серией крупных ордеров на продажу» и каскадом ликвидаций на Colend.
  - Судебный запрет тогда ещё действовал, поэтому эти перемещения, предположительно, были согласованы с Core. **Согласие: НЕ НАЙДЕНО.**

## K. Выводы для дизайна нашего продукта

**Перенять:**
- **Нативное хранение с CLTV-таймлоком и без обёртки.** Ключи у кастодиана, а CLTV означает, что никто не может переместить BTC до срока погашения.
- **Короткие блокировки со смещёнными сроками.** Сроки погашения подстраивались под календарь кредиторов.
- **Отдельная обёртка в виде сегрегированного портфеля (SPC) для каждого продукта.** Ущерб остался в пределах этого продукта; syrupUSDC и syrupUSDT не пострадали.
- **Институциональная гигиена.** Тестовые переводы и погашения раз в два месяца с уведомлением.
- **Распределение стейков по многим валидаторам.**

**Избегать:**
- **Двигателя доходности на эмиссии токена с малой капитализацией.** Реальный доход от стейкинга был ≈1.9–2.7% брутто против обещанных 5%+.
- **Хеджирования этого токена путами, выписанными его эмитентом / партнёром.** Это концентрирует wrong-way risk: контрагент слабеет ровно тогда, когда хедж должен платить. К тому же хедж был недообеспечен ($5M денежными средствами против ~$25M+ номинала).
- **Маркетинга «без кредитного риска», когда BTC кредиторов обеспечивает займ в USDC.** Заранее раскрывать LTV, кредитора в USDC и каскад распределения убытков (impairment waterfall).
- **Зависимости от партнёра, который через условия эксклюзивности может заморозить ваш хедж и запасы.** Заключать договоры с запретом на заморозку и правами вмешательства (step-in).
- **Привязки к параметру управления, который может удвоиться за ночь** (коэффициент уровня: 8k → 68k CORE/BTC).
- **Владения 3–4% обращающегося предложения токена без возможности выйти.**
- **Прекращения раскрытия после удачных месяцев.** После Q2 2025 ежемесячные данные о доходности не публиковались.

**Наше правило.** Если мы строим связку «залог BTC + долларовый займ → стратегия», стратегическая нога должна:
- быть достаточно ликвидной, чтобы погасить займ в пределах одного цикла погашения;
- хеджироваться у независимых контрагентов с надёжным обеспечением;
- зарабатывать целевую доходность *без* субсидий партнёров, поэтому стресс-тесты мы проводим с нулевой субсидией;
- сопровождаться опубликованным каскадом распределения недостачи по кредиторам.
